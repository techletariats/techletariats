<h1>Techletariats</h1>

<p>
    Techletariats is a collective of technologists, creators, and community
    members using our skills for the common good. We teach practical technical
    skills, provide free digital support to mutual aid organizations, and take
    on paid projects that help sustain our mission. Whether you're learning,
    contributing, or collaborating, Techletariats is a space where technology
    and mutual aid work hand in hand to build collective power and shared
    understanding.
</p>

<h2>Development Setup</h2>

<p>
    To set up the development environment for Techletariats, follow these steps:
</p>

```bash
# Make sure you are on the main branch
git checkout main

# Pull the latest changes from the main branch
git pull origin main

# Use the NVM to ensure you are using the correct Node version
nvm use

# Install dependencies
npm install

# Start the Next development server
npm run dev

# Start the Storybook server
npm run storybook
```

<h2>Git Workflow</h2>

<p>To follow the Git workflow for Techletariats, use the following commands:</p>

```bash
# Make a new branch for your feature, chore, or bugfix
git checkout -b feat/feature-name
git checkout -b chore/chore-name
git checkout -b fix/fix-name

# Commit your changes
git commit -m "feat: Your commit message here"
git commit -m "chore: Your commit message here"
git commit -m "fix: Your commit message here"
```
