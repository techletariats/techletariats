# Techletariats

## Getting Started

```bash
# make sure you're using the node version
nvm use

# install dependencies using npm
npm i

# launch next dev server on localhost
npm run dev

# run storybook on localhost
npm run storybook
```

## Git Workflow

```bash
# feature
git checkout -b feat/your-feature-name

# bug
git checkout -b bug/your-bug-name

# chore
git checkout -b chore/your-chore-name
```

```bash
# commit changes
git commit -m "feat(ComponentName):your commit message"
```
